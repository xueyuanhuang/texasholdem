# ♠️ 策略博弈研习社 - 德州扑克积分管理系统

一个简单易用的德州扑克锦标赛积分管理系统，支持现金游戏追踪和积分排行榜。

## ✨ 功能特性

### 🏆 锦标赛管理
- 记录比赛日期、参赛玩家
- 支持并列排名
- 自动计算积分（可自定义比例）
- 实时积分预览

### 📊 积分排行榜
- 累计积分统计
- 前三名高亮显示
- 历史排名追踪

### 💰 现金游戏追踪
- 实时买入记录（带时间戳）
- 自动计算最优转账方案
- 筹码校验功能
- 买入时间线展示

### 📜 历史记录
- 按日期分组展示
- 锦标赛 + Cash Game 合并显示
- 支持删除记录

### ⚙️ 设置管理
- 玩家管理（添加/删除）
- 自定义积分比例
- Cash Game 默认参数
- 数据导入/导出

### 🖼️ 分享功能
- 生成精美比赛结果图片
- 支持保存到相册
- 适合社交媒体分享

## 🚀 使用方法

### 在 iPhone 上使用

1. 访问：https://xueyuanhuang.github.io/texasholdem/
2. 点击 Safari 分享按钮
3. 选择"添加到主屏幕"
4. 完成！就像原生 App 一样

### 数据存储
- **本地存储**：所有数据保存在浏览器本地
- **隐私安全**：不会上传到服务器
- **导出备份**：建议定期导出数据备份

## 📱 技术栈

- 纯 HTML + CSS + JavaScript
- LocalStorage 数据持久化
- PWA 支持（可安装到主屏幕）
- 响应式设计（移动端优化）

## 🎯 默认积分比例

- 第 1 名：5 分
- 第 2 名：3 分
- 第 3 名：2 分

可在设置中自定义修改。

## 📦 数据导出/导入

在设置页面可以导出所有数据为 JSON 文件，用于：
- 换设备时迁移数据
- 定期备份
- 恢复误删数据
